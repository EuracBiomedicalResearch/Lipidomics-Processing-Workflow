Pilot Study — LC-MS Data Preprocessing

Peak detection, RT alignment, correspondence and gap filling (POS + NEG)

Author

CEMBIO-EURAC Team

Published

April 7, 2026

Overview

Study-specific instance

This is the combined preprocessing for the pilot study (BμS device comparison), running positive and negative ionization modes simultaneously via PosNegExp. See positive/ and negative/ for the single-mode counterparts.

This document handles the preprocessing of LC-MS lipidomics data:

  1. Data Import — Load raw .mzML data (local files, SQLite, or MetaboLights)
  2. Dataset Investigation — BPC visualization and reference lipid EICs
  3. Chromatographic Peak Detection — CentWave algorithm
  4. Retention Time Alignment — QC-based peak group alignment
  5. Correspondence — Feature grouping across samples
  6. Gap Filling — Fill missing peak values

Output is saved to positive/objects/ and negative/objects/, ready for Annotation.qmd.

The PosNegExp Framework

This workflow uses the PosNegExp S4 class system (defined in R/pos_neg_exp.R) to run both ionization modes in a single pipeline with minimal code duplication.

Classes

Class Wraps Lifecycle
PosNegMsExp Two MsExperiment From data load until findChromPeaks()
PosNegXcmsExp Two XcmsExperiment After findChromPeaks() onwards

Accessors — extract individual modes at any point:

posExp(mse)   # returns the positive-mode MsExperiment / XcmsExperiment
negExp(mse)   # returns the negative-mode counterpart

Dispatched xcms functions — called once, applied to both modes automatically:

findChromPeaks(), filterRt(), groupChromPeaks(),
adjustRtime(), fillChromPeaks()

perMode() — pass mode-specific arguments to a dispatched function:

filterRt(mse, rt = perMode(pos = c(10, 950), neg = c(10, 800)))

Limitation — applyAdjustedRtime() is not yet dispatched; it must be called explicitly per mode and the result re-wrapped:

mse <- PosNegXcmsExp(applyAdjustedRtime(posExp(mse)),
                     applyAdjustedRtime(negExp(mse)))

.load_mode <- function(polarity, data_dir, seq_file) {
  seq_data <- read_xlsx(seq_file, col_names = TRUE) |> as.data.frame()
  seq_data$polarity <- polarity

  if (DATA_SOURCE == "local") {
    spectra_files <- file.path(data_dir, seq_data$file_name)
    missing_files <- spectra_files[!file.exists(spectra_files)]
    if (length(missing_files) > 0)
      stop("Missing files (", polarity, "):\n", paste(missing_files, collapse = "\n"))
    readMsExperiment(spectraFiles = spectra_files, sampleData = seq_data)

  } else if (DATA_SOURCE == "sqlite") {
    sqlite_db <- if (polarity == "pos") SQLITE_DB_POS else SQLITE_DB_NEG
    if (is.null(sqlite_db))
      sqlite_db <- file.path(data_dir, paste0(STUDY_ID, "_", polarity, ".sqlite"))
    if (!file.exists(sqlite_db)) {
      message("SQLite database not found. Creating from mzML files...")
      create_sqlite_database(
        study_id  = STUDY_ID,
        polarity  = polarity,
        seq_file  = seq_file,
        data_dir  = data_dir,
        output_db = sqlite_db
      )
    }
    load_from_sqlite(sqlite_db, seq_data)

  } else if (DATA_SOURCE == "metaboLights") {
    assay_name <- if (polarity == "pos") MTBLS_ASSAY_POS else MTBLS_ASSAY_NEG
    load_from_metaboLights(
      mtbls_id             = MTBLS_ID,
      assay_name           = assay_name,
      column_mapping       = MTBLS_COLUMN_MAPPING,
      filter_column        = MTBLS_FILTER_COLUMN,
      filter_value         = MTBLS_FILTER_VALUE,
      exclude_sample_types = MTBLS_EXCLUDE_TYPES,
      polarity             = polarity
    )
  } else {
    stop("Invalid DATA_SOURCE: '", DATA_SOURCE,
         "'. Use 'local', 'sqlite', or 'metaboLights'.")
  }
}

rm(.load_mode)

perMode(): mode-specific arguments in a single call

perMode(pos = ..., neg = ...) is an S3 container that tells the dispatched method to apply different values to each mode. Here it passes distinct RT ranges to a single filterRt() call that operates on both modes simultaneously.

mse <- filterRt(mse, rt = perMode(pos = RT_FILTER_POS, neg = RT_FILTER_NEG))

applyAdjustedRtime(): explicit per-mode call

applyAdjustedRtime() is not yet an S4 generic dispatched on PosNegXcmsExp. It must be called on each mode separately and the results re-wrapped manually.

mse_raw <- dropAdjustedRtime(mse)
mse <- PosNegXcmsExp(
  applyAdjustedRtime(posExp(mse)),
  applyAdjustedRtime(negExp(mse))
)

  • < 30% NA before filling: Good — typical for well-detected features
